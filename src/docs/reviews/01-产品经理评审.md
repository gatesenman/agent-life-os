# 评审一：资深产品经理 · 逻辑一致性评审

评审范围：世界、God Mode、平行世界、智能体、经济系统、审批这六个模块之间的规则是否一致、能不能互相印证。
评审方式：通读 `core/` 引擎代码，跑 `npm test` 和 Electron 冒烟测试，并对照界面上的每一个操作。

## 结论

原先的问题不在于少了功能，而在于没有一条所有模块都遵守的“物理定律”：钱、时间、能量、随机数各算各的，所以平行世界一分叉就暴露出不一致。本轮先定义了**世界终极公式**，再让引擎每一步都自动校验它。

## 世界终极公式

```
S(t+1) = F( S(t), a(t), h(t) ; R, σ )
```

- `S(t)`：完整世界状态（时间、能量、心情、应用状态、订单、钱包流水、预算计数、记忆、RNG 计数）。
- `a(t)`：智能体动作（规则大脑 / LLM）。
- `h(t)`：人类输入。除“审批”以外，只有 God Mode 才能产生 h(t)。
- `R`：规则（预算策略、世界规则）。
- `σ`：种子（DNA 种子 + 分支种子）。

七条定律，实现位置在 `core/formula.js` 的 `checkInvariants()`，`engine.step()` 每一步之后调用：

| 定律 | 内容 | 引擎中的保证 |
|---|---|---|
| L1 货币守恒 | 余额 ≡ Σ 流水 | 每步核对，误差 > 0.005 即判定违反 |
| L2 货币边界 | 只有 fund / earn / spend 三类流水；spend 必须带 approval；余额不为负 | 支付适配器只认这三类；`settle()` 写入 approval |
| L3 因果 | 事件序号单调；结果、收支事件必须带 cause | `engine.emit()` 自动挂上触发它的动作 id |
| L4 时间之箭 | 世界时间单调不减，每个动作 Δt > 0 | 每步比较前后世界时间 |
| L5 熵与需求 | 能量每小时 −2（休息除外），能量 ∈ [0,100]，心情 ∈ [0,1] | `simWorld.advance()` 按时间扣能量 |
| L6 可复现 | 相同 σ 与 h ⇒ 相同轨迹 | 所有 id 由计数器生成；PRNG 记调用次数，快照可快进 |
| L7 分支隔离 | 分叉后互不影响，不合并 | 每个世界一个独立引擎、独立数据目录、按世界路由审批 |

违反任何一条，都会在时间线上记一条“违反定律”的错误事件，并计入 `violations`。测试与冒烟测试都要求 `violations=0`，最近一次冒烟结果：`worlds=3 steps=74/74/67 violations=0`。

## 主要发现与修复

| # | 发现 | 严重度 | 修复 |
|---|---|---|---|
| 1 | 事件、邮件、支付流水的 id 用 `Date.now()` 生成，同一种子两次运行的结果不一样，从快照重放也对不上（违反 L6） | 高 | 全部改成计数器：`${worldId}:${seq}`、`m{n}`、`mock_{流水序号}` |
| 2 | PRNG 只有部分方法计数，从快照恢复后随机序列错位 | 高 | `wrapRng` 统一计数；`SimWorld.restore` 用计数快进 |
| 3 | 能量只在做动作时扣，时间流逝不扣，“熵”没有体现 | 中 | `advance()` 按时间扣能量，休息除外（L5） |
| 4 | 收入、结果事件说不清“为什么发生” | 中 | 自动挂 `cause`；流水记录 `approval` / `cause` / 世界时钟（L3） |
| 5 | 多个世界的审批 id 会撞车，批准一笔可能扣到别的世界 | 高 | 审批 id 带世界前缀 `w2:ap3`，`Multiverse.approve()` 按前缀路由（L7） |
| 6 | “解锁”语义模糊：审批算不算干预？分叉算不算？ | 中 | 统一定义为 God Mode：暂停、单步、接管、注入、分叉、删除世界都要先开 God Mode；审批是守护职责，只读模式下也能做 |
| 7 | 同一种子再次创世时，上一轮人生的长期日记混进本轮（本轮评审在记忆页发现同一篇日记出现 3 次） | 高 | 新创世时把旧的 `memory.json` 归档为 `memory.<时间戳>.json`，从空白记忆开始；审计日志只追加、永不清空 |
| 8 | 长期记忆显示的是电脑时间，和世界时钟对不上 | 低 | 记忆记录世界时钟（如“第2天 20:00”） |
| 9 | “孵化新智能体”会直接清掉所有平行世界，事先没有任何提示 | 高 | 新增确认对话框：可以输入 DNA 种子，并提示“将结束当前 N 个世界” |
| 10 | 删除父世界后，子分支在分支图上找不到父节点 | 中 | 删除时把子分支重新挂到被删世界的父世界；主世界不可删除 |

## 测试

- `test/headless.test.js`：80 步零违反、审批前不扣款、接管、审计日志路径。
- `test/multiverse.test.js`：两次独立运行 40 步完全一致；从第 10 步快照重放与原世界逐条一致；两个分支并发运行，各自分歧、源世界不受影响；审批只扣对应世界的钱。

## 复审 v0.3：世界维度体系与镜像世界（2026-10-13）

**结论：通过。** 新维度都落在终极公式 S(t+1)=F(S, a, h; R, σ) 内。新增的 L8–L16 与原有的 L1–L7 一样，每一步检查。最新冒烟测试中 3 个世界合计运行约 870 步，定律违反为 0。

**审查要点**

- **规则与状态分离**：
  - God Mode 改法则参数属于 R，从下一步起生效，不改写历史。
  - 天启属于 h(t)，同样必须守律。
  - “复活”在引擎层被 L8 拒绝，界面上显示为禁用并注明原因。这是好的产品表达：观察者明白，有些事连上帝也做不到。
- **两种货币**：粮币与美元钱包分开，避免把虚拟社会的财富与操作者的真实资金混在一起。保留。
- **主角继承**：智能体随主角死亡而交棒给后代；无人可继承时“血脉断绝”，世界停止。界面和时间线都写明“账户仍归人类操作者”。
- **可比性**：平行世界对比新增“生命与文明”表格和人口走势；分叉时可以单独设定疫病、突变和灾害率。“同一个人，不同法则”的实验可以完整走通。

**本轮发现并已修复**

- 大事记被出生、死亡等家族事件挤掉。现已拆分为“世界事件”流。
- 环境曲线的横轴沿用了收支图的“第 1 笔流水”。现改为纪元年。

**遗留**

- 时间压缩较高时（冒烟测试用每日 60 年），一个世界日就跨越两代人，长期记忆几乎全部“渐淡”。这符合 L16，但默认值保持 4 年/日更易于观察。
- 粮币的通胀模型较简单。
