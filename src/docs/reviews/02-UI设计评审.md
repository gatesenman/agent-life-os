# 评审二：资深 UI 设计师 · 视觉一致性走查

## 参照物 “zcode” 的理解

搜索结果显示，ZCode 是 z.ai 为 GLM 系列模型推出的 Agentic Development Environment（智能体开发环境），是一个桌面开发工具，并不是设计规范或设计工具。官方文档：https://zcode.z.ai/en/docs/welcome。第三方设计分析（Fudge）：https://design.withfudge.com/share/zcode.z.ai-design。

因此本轮把“zcode”理解为**对标 ZCode 这类专业智能体桌面工具的界面语言**：

- 深色优先；
- 用明暗分层代替重阴影；
- 1px 低对比描边；
- 只用一个克制的强调色；
- 信息密度高的面板布局；
- 用等宽字体显示数字和 id。

Fudge 的分析里给出的参数是：面板圆角 16px、内边距 24px、区块间距 20px，字体 Geist / Geist Mono。我们保留 Inter 加中文回退字体，因为中文排版更稳。间距按本应用的信息密度收紧为卡片内边距 16–18px、卡片间距 12–16px，但整套界面保持统一。如果 “zcode” 另有所指，这套对标需要再调整。

## 走查清单

| 维度 | 现状 / 发现 | 处理 |
|---|---|---|
| 间距 | 概览页的世界画面被挤到卡片下半部并被裁切（before-overview） | 视图改为固定高度网格；虚拟机画面用容器查询 `min(100cqw,160cqh)` 等比缩放并居中 |
| 字体 | 统一使用 Inter Variable 加中文系统字体回退；数字用等宽数字（`.num`） | 保持 |
| 颜色 | 只有一个强调色 #8b8dff，另有语义色：收入 #6fd3a0、警示 #e7b65c、错误 #ef8a8a。平行世界的区分色只用在世界圆点和曲线上 | 世界列表里的走势小图原本一律是强调色，现改为各世界自己的颜色，和分支图对应 |
| 对比度 | 三级文字 #6b6f78 在背景 #0a0b0d 上只有 3.91:1，低于 WCAG AA 要求的 4.5:1 | 调成 #858a94，达到 5.68:1（卡片底色上 5.17:1）；二级文字 7.88:1，强调色 6.89:1 |

| 图表 | 余额面积图被横向拉伸，折线比填充短一截；柱状图柱子过宽（before-wallet） | 改为按真实像素宽度绘制（ResizeObserver），去掉 `preserveAspectRatio="none"`，柱宽设上限 |
| 浮层 | 审批弹窗盖住了流水表和活动列表，多笔审批时会叠成一列（before） | 改为卡片堆叠：最上面一张完整显示，后面露出最多 2 张的边缘，并提示“另有 N 笔待审批”，点击可跳到收支页的完整审批列表；收支页本身不再显示浮层 |
| 虚拟机画面 | “休息”按钮压在菜单栏的时钟上 | 世界元素坐标下移到 [1130,52] |
| 标题栏 | 面包屑写成“Agent Life OS / 沈未央 / 概览”，信息重复；也看不出当前观察的是哪个世界 | 面包屑改为“角色 / 页面”，并加上世界切换器（彩色圆点 + 世界数量） |
| 动效 | 并排对比页的卡片一直不可见：动画状态（variants）没有从父容器传下来；切换页面时，旧视图的退出动画卡住，新视图出不来（收支页整页空白） | 标签页容器统一使用 variants；视图切换改为 `popLayout`，不再等旧视图退出 |
| 时间线动效 | 新事件不断涌入时，最顶上几条一直处在淡入途中，看上去发灰 | 首屏用弹簧动画逐条入场；之后的新事件改为 0.26 秒的快速淡入，再加 1.2 秒的高亮渐隐 |
| 状态 | 空数据：图表显示“数据积累中…”或“暂无收支记录”，审批列表显示“没有待审批的支出”，活动列表显示“暂无记录”，分支图有空状态卡片。错误：IPC 出错时弹出错误提示。加载：新建对话框的按钮显示“正在创世…” | 补全 |
| 无障碍 | 只有图标的按钮没有可读名称 | `MButton` 自动把 `title` 作为 `aria-label`；对话框加上 `role="dialog"`、`aria-modal`；保留 `:focus-visible` 描边；遵守系统“减少动态效果”设置 |

## 复审 v0.3：新页面视觉（2026-10-13）

**结论：通过。** 新页面沿用了原有规范：单一强调色、玻璃卡片、Inter 加中文回退字体、lucide 图标、framer-motion 弹簧动效、尊重“减少动态效果”。没有 emoji，界面源码、生成数据和渲染文字都经测试扫描。

**本轮发现并已修复**

1. 人生阶段条的当前阶段胶囊不可见。原因是 `.stg span` 覆盖了胶囊的绝对定位。
2. 家谱前几代节点被推到 x ≈ 10⁶ 之外。原因是出生年为负的始祖被误当作“有期望位置”。修复后，家谱改为“直系祖先链 6 代、兄弟姐妹与伴侣、子孙两代”的可读视图。
3. 镜像世界侧栏的地点检查卡停在透明状态。原因是动态挂载的 Card 继承不到父级 variants。现改为 variants 驱动。侧栏卡片也不再被压缩重叠。
4. 街区白天仍显示为夜景。原因是帧时间被截断后，显示时刻追不上世界时间。现在偏差超过 2 小时直接对齐，并提高了日间材质与天光亮度。
5. 地球夜面几乎全黑。现增加陆地底色与海岸线描边，夜面也能辨认大陆。
6. 卡尔达肖夫仪表的刻度标签被裁切，已扩大视口。食物链和资源图补上图例。
7. 平行世界对比中，“生命与文明”卡移到首屏可见位置。

**设计亮点**

- 地球到街区的切换有飞行和渐隐过渡；居民标签和地点光柱使用世界颜色。
- 天气标签用图标显示天气、温度、时刻、纪元季节和太阳高度。
- God Mode 编辑工具条只在 God Mode 下出现。
- 数据署名常驻画面底部，满足 ODbL 要求。

**遗留**

- 本环境是软件渲染（约 5–10 fps），已加入自适应画质。真实 GPU 上需要再看一次阴影效果。
- 家谱中跨代伴侣的连线会斜穿行间，后续可以改为折线。
