# 08 反思与三轮进化（v0.4.2 → v0.5.0）

> 日期：2026-10-22（北京时间）。基于 06 竞品分析、07 开源分析，连续做了三轮自进化。每轮都要求：L1–L18 零违反，端到端测试全绿。

## 一、对我们产品的诚实反思

### 我们已有的独特优势
1. **三条赛道交汇**：社会模拟（Smallville / Sid）+ 角色人格（Character.ai 类）+ 电脑操作（Operator / Agent-S），竞品没有一家同时覆盖。
2. **可校验的世界公式**：S(t+1)=F(...)，L1–L18 每步全检；竞品大多只有“跑得通”，没有“定律”。
3. **人类边界硬约束**：花钱必须审批、接管期间智能体停手（L18）；比 Operator 的“建议确认”更硬。
4. **平行世界可复现**：同一种子分叉后轨迹独立（L6 / L7）。

### v0.4.2 的关键缺口（对应竞品）
| 缺口 | 对照 | 影响 |
|---|---|---|
| 记忆只有“短期 + 日记 + 教训”，没有重要度 / 检索 / 反思 / 日计划 | Generative Agents 四件套 | 角色“记得但不成长”，目标选择短视 |
| 电脑操作缺少卡死检测与步数预算 | OpenHands StuckDetector、browser-use 失败预算、Project Sid 行动觉察 | 同一动作反复无效时只能靠人工接管 |
| 没有运行可观测性面板 | The Sims 念头气泡、LangSmith / AgentOps | 用户看不懂“这一步为什么慢 / 用了什么大脑 / 定律是否还绿” |
| 反思压力阈值过低 / 洞见重复 | Smallville 阈值 150 | 第一轮试验中出现 39 次反思重复同一洞见 → 已校正 |

### 刻意不做的（路线图，不在本轮）
- 与角色直接对话（Character.ai 风格）
- 多智能体之间的社交对话与信息传播（AI Town / OASIS）
- 真实视觉模型的 OSWorld 任务集评测（需要用户提供模型密钥）
- 把“创世中心”统一命名到界面（等待用户确认）

## 二、三轮进化

### 第一轮：记忆流心智（对照 Smallville / AI Town）
**改动**
- `core/memory.js`：每条观察带重要度（1–10）；`retrieve(query,k)` = 新近度 × 0.98^序 + 重要度 + 1.5 × 关键词相关度；累计重要度 ≥ 150 触发 `reflect()`，产出带证据的洞见（`insight`）；每日 `makePlan()`。
- `core/engine.js`：每步调用 `cognition()`（计划 / 反思 / 检索），只写心智、不改钱/时间/人口。
- `core/brain.js`、`core/desktop/session.js`：决策提示注入相关记忆与今日计划。
- `src/views/Memory.jsx`：今日计划、反思与洞见、记忆检索得分表。
- 新增 `test/memory.test.js`。

**验证**：单元测试通过；端到端“其余页面巡检”断言今日计划 ≥ 1、反思 ≥ 1、洞见 ≥ 1。第一轮快测时反思阈值过低导致洞见重复 → 第二轮前把阈值调到 150 并去重。

### 第二轮：电脑操作可靠性（对照 Sid 行动觉察 / OpenHands / browser-use）
**改动**
- `core/desktop/session.js`：
  - **卡死检测**：同一动作 + 同一屏幕签名连续 3 次校验失败 → 放弃当前目标并换目标（`rel.stuck++`）。
  - **步数预算**：单目标有效动作 > 120 → 熔断（`rel.budget++`）。
  - **可靠性指标**：动作数、校验通过率、目标完成率、卡死自救、预算熔断，随桌面视图暴露。
- `src/views/Desktop.jsx`：新增「可靠性」卡片。

**验证**：端到端全绿（35/35）；巡检报告：校验通过 100%、目标完成约 89–91%、卡死自救 0、预算熔断 0、定律违反 0。

### 第三轮：运行可观测性（对照 The Sims 可解释性 / AgentOps）
**改动**
- `core/engine.js`：每步写入轨迹 `{step, clock, ms, source, action, verify, events, laws, violations}`；`traceSummary()` 给出 P50/P95、决策来源分布、校验率、定律检查次数。
- `src/views/Activity.jsx`：顶部「运行可观测性」面板（耗时火花线、定律检查、动作校验、决策来源条、最近 12 步表）。

**验证**：端到端巡检断言可观测性面板存在，且最近 N 步定律违反为 0；示例：最近 60 步 P50 1 ms / P95 3 ms，定律检查 1080 次（60×18）。
