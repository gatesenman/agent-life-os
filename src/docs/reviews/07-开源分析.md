## 关键启示
1. **心智要分层**：观察（短期）→ 带分数的记忆流 → 反思洞见 → 计划。只有前两层的智能体"记得但不成长"。
2. **可靠性来自"自我觉察"**，不只靠更强的模型。OpenHands 的 StuckDetector 和 browser-use 的失败预算都很简单，但很有效。
3. **可观测性是这类产品的界面核心**。开源项目大都只有日志；把每步耗时、决策来源、校验率做成仪表盘，是我们能做出差异的地方。
4. **确定性优先**：开源实现大量依赖 LLM 打分。我们坚持"无 LLM 也能跑、同一个种子轨迹一致"（L6）。所以第一轮用确定性算法实现，LLM 只是增强。
