# 评审三：终端用户旅程

用户画像：第一次使用的操作者。懂一点 AI，但没读过设计文档。目标是“养一个虚拟人，看 TA 怎么生活和赚钱，必要时出手”。

## 旅程地图

| 阶段 | 用户想做什么 | 修复前的体验 | 痛点 | 修复 |
|---|---|---|---|---|
| 1. 首次启动 | 搞清楚这是什么、自己能做什么 | 一打开世界就在跑，没有任何说明 | 不知道“只读”是什么意思，不知道钱是谁的 | 新增 4 步引导：欢迎 → 默认只读与 God Mode → 花钱要你批准 → 平行世界。可跳过；标题栏的帮助按钮可随时重新打开 |
| 2. 创建世界 | 用自己的种子创建一个人 | 侧边栏按钮点一下就随机重建，还会清掉所有平行世界 | 结果不可控，而且会悄悄丢掉数据 | 新增“孵化新智能体”对话框：输入或随机生成 DNA 种子，说明“同一个种子永远得到同一个人”，并提示会结束当前 N 个世界。创世后自动跳到身份页 |
| 3. 认识这个人 | 看 TA 是谁 | 身份页信息齐全 | 档案卡容易被误认为真实证件 | 档案卡带 FICTIONAL 水印、“虚构档案”标记和法律归属说明（保持） |
| 4. 观察 | 看 TA 在做什么 | 概览页画面错位，活动列表文字重叠 | 第一眼就显得不专业 | 布局修复（见 UI 评审）；时间线新条目有高亮；记忆改用世界时钟显示 |
| 5. 想干预 | 暂停或接管 | 只读模式下按钮是灰的 | 用户可能不知道为什么灰 | 世界画面和分叉面板顶部都写明“开启右上角 God Mode 后才能干预”；锁形按钮上直接写“只读观察 / God Mode”；引导第 2 步专门讲这一点 |
| 6. 批准支出 | 处理 TA 的购物请求 | 弹窗层层叠加，遮住内容；分不清是哪个世界的请求 | 处理不过来，还可能批错世界 | 改为卡片堆叠，并标出所属世界；收支页有跨世界的完整审批列表；审批 id 带世界前缀，只扣对应世界的钱 |
| 7. 分叉平行世界 | 看看“如果 TA 更节俭会怎样” | 分叉之后很难看出两个世界差在哪里 | 看不到结果 | 侧边栏有“平行世界”入口和数量标记；分叉面板有快照滑杆、分支种子、性格与预算滑杆；分支图可以直接点击切换；“并排对比”展示余额曲线、基因差异、时间线的共同历史与分歧 |
| 8. 回到主世界 | 切回去 | 没有入口 | 迷路 | 标题栏的世界切换器在任何页面都能用 |

## 本轮发现并修复的可用性问题（Top 6）

1. **没有引导，用户不理解只读和 God Mode** → 4 步引导加随时可开的帮助按钮。
2. **新建智能体会悄悄清掉所有世界** → 确认对话框，可输入种子，并给出警示。
3. **审批弹窗遮挡内容，而且不标所属世界** → 卡片堆叠、世界标签、收支页集中审批。
4. **灰掉的按钮不说原因** → 面板内提示、按钮文字和引导三处同时说明 God Mode。
5. **切换页面偶尔出现整页空白**（退出动画卡住） → 视图切换改为 `popLayout`。
6. **记忆里混入上一轮的日记，时间也对不上** → 新创世时归档旧记忆；记忆按世界时钟显示。

## 仍待改进

- 引导目前是弹窗式，下一步可以做成在真实界面元素上高亮的分步提示。
- 平行世界最多 8 个，到达上限时只有错误提示，还没有给出“删除哪个”的建议。
- 真实支付、邮箱、电话需要用户自己的账号（见 README），首次接入流程没有向导。

## 复审 v0.3：观察一个家族的数百年（2026-10-13）

按冒烟测试的脚本走了一遍：每世界日 60 年，3 个世界，17 个页面。

1. **镜像世界 → 地球**：一眼就能看到锚点“上海 · 陆家嘴”，天气标签告诉我此刻是几点、什么季节。切到街区后，真实的上海中心、环球金融中心、金茂都在，居民正走向写字楼。
2. **点击居民列表或地点**：右侧出现检查卡，列出此刻在场的人，“飞到这里”可以让相机飞过去。
3. **生命与家族**：能看到主角处于第几代、几岁、什么人生阶段；家谱里能找到上一代主角及其死因（悬停显示）。“主角更替 N 次”与时间线上的继承事件对得上。
4. **文明与环境**：卡尔达肖夫从 0.5 左右缓慢上升，科技树依次点亮，大事记里有洪水、天花、地震。维度体系页让新用户理解“这个世界遵守哪些规则”。
5. **God Mode**：法则页的滑块和天启可以直接操作。地图上可以选“医院”后点地面新建，也可以改名、移动、拆除地点；拆到只剩最后一处住宅时会被拒绝。
6. **平行世界对比**：A/B 世界的生命与文明逐项对照，差异行高亮；“冒险的平行自我”分叉时设定了更高的疫病率（0.2）和灾害率（0.12），可以在这里与主世界比较。

**本轮修复**：God Mode 下地点卡不显示、家谱空白、白天街区仍是夜景。这三处都直接影响旅程，现已修复。

**遗留**：新手引导还没有介绍镜像世界和生命页，下一轮补一步引导卡。
